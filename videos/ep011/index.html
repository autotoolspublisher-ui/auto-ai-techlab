xlsx・冷えた状態からibisOffice 0.87, 0.78, 0.80秒（中央値 0.80）、Excel 6.61, 7.60, 7.60秒（中央値 7.60）。約9.5倍

わかったこと

  • 公式と同じ 13.7MB の xlsx で、ibisOffice は 0.80秒、Excel は 7.60〜7.73秒（中央値）。約9.5〜9.7倍で、公式の27倍とは条件がちがう
  • ibisOffice も Excel も、先に起動しておいても速くならなかった
  • 第8回の ✕ のうち、集計表の ####（SUM・AVERAGE・VLOOKUP）は直り、縦中横とふりがなは表示されないままだった
  • 保存したファイルは Word・Excel で確認の窓なしに開き、ibisOffice が表示できない縦中横とふりがなもファイルには残っていた

結果の範囲

  • 1台の PC での結果です。xlsx の速さは各条件3回、ほかは1回で、一般化はしません
  • Excel は読み込み中に画面を撮れる間があき、終わりの前で最大約0.5〜0.6秒あいたため、Excel の値は粗いです
  • 公式の表とは OS・PC・ibisOffice の版・測り方が違います。27倍が正しいかどうかは、この回では言えません
  • PowerPoint は確認の窓で止まり、pptx の比べはできていません
  • #### が直った理由は、0.8.4 のリリースノートの「列の幅と行の高さを Windows の Excel に合わせた」によると考えられますが、推測です
  • 保存の往復は、3つの文書・1か所の書き足し・各1回です。大きな変更や、ほかの機能の保存は試していません
  • 測り方のつまずきで2回測り直しました（ibisOffice が出力の口を引き継いだ件、Excel の終わりの判定に「題にファイル名が出てから3秒」を足した件）。やり直す前の回は結果に入れていません
  • W2 のページ番号が中央に出た・W2 の折り返しの位置が Office と違った・X1 の見出しが太字で出た、は結果を見てから気づいたことで、採点の外です

よくある質問

ibisOffice は本当に Excel の27倍速いですか？

この回の Windows の PC では、公式と同じ 13.7MB の xlsx で ibisOffice 0.80秒、Excel 7.73秒（起動しておいてから、中央値）で約9.7倍でした。公式の27倍は macOS・別の版・各1回の測定で、条件が違います。

第8回（Web 版）で出た「####」は直りましたか？

デスクトップ版 0.8.4 では SUM・AVERAGE・VLOOKUP の値が出ました。縦中横（「10月20日」が「1月2日」と出る）とふりがなの表示は、第8回と同じく ✕ でした。

ibisOffice で保存したファイルを Office で開けますか？

この回で試した3つの文書（縦書き・方眼の申込書・集計）は、1か所書き足して保存したあと、Word・Excel で確認の窓なしに開け、書き足した文字もありました。各1回の結果です。

ibisOffice で表示できない縦中横やふりがなは、保存すると消えますか？

この回では消えませんでした。保存したファイルを Word で開くと「10月20日」、Excel で開くと「ヤマダ」「ハナコ」が出ました。
