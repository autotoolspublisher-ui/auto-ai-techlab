わかったこと

  • Windows ではモデルの読み込みで止まった。WSL2 の Ubuntu に替えると動いた（公式の要件は Linux と NVIDIA GPU で、Windows の記載はない）
  • この PC では、597秒の音声がバッチ64で0.587秒、Whisper large-v3 の既定は57.053秒で、約97倍の差があった。ただし1セリフずつ入れた合計では約8倍だった
  • 誤り率は、strict では Whisper が低く（11.60%／10.83%）、読み上げ用の文を正解にした kana では Haas が低かった（4.79%／5.31%）。物差しによって入れ替わる
  • 雑音と1.5倍速の結果も物差しによって入れ替わった。雑音は strict では Haas の誤りが少ないが、10dB の kana は Whisper が少ない。1.5倍速は strict では Whisper が少なく、kana では Haas が少ない
  • Whisper は無音でもノイズだけでも「ご視聴ありがとうございました」と書いた。Haas は無音では何も書かなかったが、ノイズだけでは「善悪のこともある。」と書いた
  • 読み間違いのテストで気づけたのは10個のうち2個で、Haas も Whisper も同じだった。4個は読み間違いのまま正解の文が出力され、気づけなかった
  • 234セリフのうち141個（Haas）は strict で正解と一致しないので、不一致をそのまま読み間違いの候補にすると多すぎる

よくある質問

Haas-ja-v1.0 は Windows で動きますか？

この回では、Windows の Python 3.12 で入れてもモデルの読み込みで Triton がないというエラーになりました。WSL2 の Ubuntu では動きました。公式の要件は Linux と NVIDIA GPU で、Windows の記載はありません。Windows で GPU 版の PyTorch を入れる、Triton をソースから入れる、などは試していません。

Whisper よりどのくらい速いですか？

RTX 5070 Ti で597秒の音声を文字にするのに、Haas はバッチ64で0.587秒、Whisper large-v3 は既定で57.053秒でした（約97倍）。バッチ1でも1.088秒で約52倍です。1セリフずつ入れた合計（234セリフ）では 18.59秒と149.54秒で約8倍でした。公式の約15〜17倍は、Whisper もバッチ256で H200 の値で、条件が違います。

Whisper より正確ですか？

どちらとも言えません。合成音声の234セリフで、CER strict は Haas 11.60%、Whisper 10.83%、読み上げ用の文を正解にした kana は Haas 4.79%、Whisper 5.31% でした。物差しによって入れ替わります。人の声では試していません。

雑音があると精度は落ちますか？

第13回の78セリフの CER strict は、そのままで Haas 13.00%、Whisper 12.67%、ピンクノイズ SNR 0dB で Haas 16.54%、Whisper 18.94% でした。strict では雑音で Haas の誤りが少ないですが、SNR 10dB の kana は Whisper が少なく、物差しによって入れ替わります。

声のない音声でも文字が出ますか？

無音30秒では Haas は何も書かず、Whisper は「ご視聴ありがとうございました」と書きました。ピンクノイズだけの30秒では Haas が「善悪のこともある。」、Whisper が「ご視聴ありがとうございました」と書きました。各1回の結果で、理由は調べていません。

カスタム語彙は効きますか？

語があるセリフのうち正しく出た数は、ibisOffice が9個で 1→9、TypeScript が4個で 0→4、Claude が3個で 0→3 に増えました。DuckDB は5個で 0→1 にとどまり、tsrs はもともと8個とも出ていました。語がないセリフに語が出ることはありませんでした。

音声の読み間違いを文字起こしで見つけられますか？

読み間違いの10文で試すと、気づけたのは Haas・Whisper とも2文（値、行）でした。4文は読み間違いのまま正解の文が出力されて気づけず、4文は直した読みでも正解と違って区別できませんでした。正解と比べずに2つの音声の出力を比べると、Haas は5文、Whisper は6文で文字が変わりました（結果を見てから数えた見方です）。
