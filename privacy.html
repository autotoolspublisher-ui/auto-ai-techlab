このページでは、YouTube チャンネル「全自動AIテックラボ」（@auto-ai-techlab、以下「当チャンネル」）の運営者が使う動画アップロード用ツール「AI Techlab Uploader」と、このウェブサイトでの情報の扱いを説明します。

1. 「AI Techlab Uploader」について

「AI Techlab Uploader」は、当チャンネルの運営者が、自分のチャンネルに動画をアップロードして公開予約するために使う、個人用のツールです。運営者以外の方が使うことは想定していません。

Google アカウントで許可を求める範囲（YouTube Data API）

  • youtube.upload：当チャンネルへの動画のアップロード、タイトル・概要欄・公開予約日時・サムネイルの設定
  • youtube.readonly：認証したチャンネルが当チャンネルであることの確認
  • 使うのは、運営者自身の Google アカウントと当チャンネルの情報だけです。ほかの方の Google アカウントやチャンネルの情報は扱いません。
  • Google から受け取る認証情報（トークン）は、運営者のパソコンの中にだけ保存し、外部のサーバーには送りません。
  • YouTube から受け取った情報を、第三者に販売・提供したり、広告に使ったりすることはありません。
  • このツールによる Google API から受け取った情報の利用は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。
  • 許可は、Google アカウントのサードパーティのアクセスからいつでも取り消せます。取り消すと、保存されたトークンは使えなくなります。

2. このウェブサイトについて

  • このサイトは、閲覧した方の名前・メールアドレスなどの個人情報を集めていません。アクセス解析や広告のための Cookie も使っていません。
  • 動画のサムネイル画像は YouTube（Google）のサーバーから、文字のデータ（フォント）は Google Fonts から読み込んでいます。そのため、閲覧した方の IP アドレスなどが Google に送られます。扱いは Google のプライバシーポリシーに従います。
  • このサイトは GitHub Pages で公開しています。GitHub がアクセスの記録を取る場合があります（GitHub のプライバシーに関する声明）。
  • 「チャンネル登録」などのボタンは YouTube へのリンクです。YouTube 上での扱いは YouTube の規約とポリシーに従います。
